Política de privacidad de PodClipper

Última actualización: 12 de noviembre de 2026.

Quién la usa

PodClipper es una herramienta interna del canal Haber Estudiao Podcast. Solo se conecta a las cuentas del propio podcast. No ofrece registro a terceros.

Qué datos usa

  • Vídeos del propio canal: descarga los episodios publicados para recortar clips.
  • Acceso a YouTube (API de YouTube Data, permisos youtube.upload y youtube.force-ssl): para subir los clips como Shorts al canal del podcast y para leer y responder los comentarios de esos clips.
  • Comentarios de los clips: texto, autor y fecha, para que el equipo los lea y responda.

Dónde se guardan

Todo se guarda en el ordenador del equipo del podcast: los clips, la base de datos y las credenciales de acceso. No hay servidores externos de PodClipper.

Con quién se comparten

Con nadie. Los datos solo se envían a las propias plataformas (YouTube, Instagram, TikTok) para publicar en ellas. Para elegir los mejores momentos de cada episodio, la transcripción del episodio, que ya es público, se envía a la API de Google Gemini. No se venden datos ni se usan para publicidad.

El uso de los datos recibidos de las API de Google cumple la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado. PodClipper usa los Servicios de la API de YouTube; consulta también la Política de privacidad de Google.

Cómo retirar el acceso

El acceso de PodClipper a la cuenta de Google se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al retirarlo, las credenciales guardadas dejan de funcionar y se borran.
